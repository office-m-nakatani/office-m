### 選ぶときの条件（2026-09-08 ユーザー指示）

- 人物が写るなら **日本人／スーツ（ジャケット＋襟シャツ＋ネクタイ）できちっとした身なり／
  引き締まった体型**
- **太った人・崩れた着こなし（裾出し・ネクタイ緩め・腕まくり）は使わない**
- 広告に使うので **商用利用可**。人物が写るものは **モデルリリースあり** のものを選ぶ
- 御社の事務所・デスクを撮った写真がいちばん確実です（権利の心配がない）
