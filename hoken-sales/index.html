手数料の基礎知識

5L・7L・一時払……なぜ率が違うのかを短く整理

「5L」「7L」とは何か（払込期間の読み方）

商品略称の「L」は払込満了（Limited pay）を表す業界の書き方です。数字＋L＝その年数（または年齢）で保険料の払込が終わるという意味。

  • 5L・7L・10L … 5年・7年・10年で払込満了（短期払）。法人の逓増定期や終身保険の短期払でよく登場
  • 60L・65L … 60歳・65歳で払込満了（歳満了）
  • 終身払 … 一生涯払い続ける。月々は最も安いが総額は読めない
  • 一時払 … 契約時に全額を一括で払う

同じ保障でも払込期間が短いほど1回あたりの保険料は大きくなり、後述のとおり手数料率は低く設定されるのが通例です。

ANP（換算年払保険料）と一時払の10%換算

成績や手数料の物差しになるのがANP（Annualized New Premium＝換算年払保険料）。月払は×12、半年払は×2、年払はそのまま。

一時払は1年分に直せないので、一時払保険料の10%（10分の1）をANPと数えるのが業界の代表的な慣行です（挙績評価やMDRT基準などで使われる考え方。会社により扱いは異なります）。

例：一時払1,000万円 → 換算ANP 100万円。月払3万円 → ANP 36万円。「一時払は保険料が大きいのに成績はそれほど伸びない」のはこの換算のためです。

初年度コミッションと継続コミッション（L字型）

生保の販売手数料は初年度に厚く、2年目以降は薄く長くの「L字型」が基本形。初年度は募集コスト（面談・設計・診査対応）への対価、継続分は保全・アフターフォローへの対価という建て付けです。

  • 初年度：ANPに対して数十%（商品・会社・チャネルで大きく差がある）
  • 継続：2年目以降、数%を数年〜10年程度（2〜10年目など会社ごとに設計が違う）

継続コミッションは契約が続いていることが条件。早期解約されると入らないうえ、初年度分の戻入（チャージバック）が発生する会社が多い点に注意。

なぜ一時払・短期払（5L・7L）は率が低いのか

手数料の原資は保険料に含まれる付加保険料（事業費）です。平準払は長期間にわたり事業費を回収できるため初年度に厚く払えますが、払込期間が短いほど回収の余地が小さくなります。

  • 平準払（終身払・長期払込） … 率が最も高い層。初年度ANP比で数十%
  • 短期払（10L→7L→5L） … 払込が短いほど段階的に率が下がるのが通例
  • 一時払 … 率は保険料に対して数%以下。ただし保険料自体が大きいので額はまとまりやすい

「率の高い商品」へ誘導する提案は保険業法上も募集品質上も禁物。払い方はお客様の資金繰りとニーズで決め、手数料は結果——この順番を崩さないことが大前提です。

手数料体系の実際（ベース＋ボーナス・継続率連動）

乗合代理店ではベース手数料＋各種ボーナスの二階建てが一般的。ボーナスは挙績（販売量）や継続率（13ヶ月・25ヶ月時点で契約が残っている割合）に連動します。

2022年以降、金融庁の要請で大手生保は代理店手数料の「率」の考え方の開示を進めていますが、個別の料率表は今も各社・各代理店契約ごとの世界です。だからこそこのツールでは自分の料率を設定して管理する方式にしています。

継続率が悪化するとボーナス階層が下がり、同じ挙績でも実収入が大きく変わります。解約されない販売（意向把握・アフターフォロー）が最大の収入対策です。

早期解約の戻入（チャージバック）

契約から一定期間（例：1〜2年）内に解約・失効すると、受け取った初年度コミッションの全部または一部を返すルールが一般的です（経過月数に応じて逓減）。

見込み数字を読むときは「契約＝確定収入」ではなく、初期は仮の数字という感覚を持つこと。このツールの継続C見込みも継続率100%前提の上限値として見てください。

このツールの数字は自分の営業管理のための概算です。お客様への説明・募集資料には使わないでください（募集文書は所定の審査を経たものだけを使用）。
