種明かし

国民年金の保険料も同じです。納めていない月でも、免除・猶予を申請した月は記録に残り、障害年金・遺族年金の要件も守られます。何もしない未納の月は、まるごと記録の外。分けるのは、申請書1枚です。

面談の最初のひと言

「国民年金を納められなかった時期に、申請書を出されましたか。」

責める問いではありません。ねんきん定期便の月別の欄を一緒に開き、未納・免除・猶予の月を数えるところから始めます。

30秒の核心現場あるある逆転劇場明日の3つの問い3本の線未納と免除年齢と窓口
30秒の核心

お客様に伝えるのは、この3行だけ。

自営業やフリーランスの方の備えを考えるとき、民間の商品から話すと、いちばん大きな土台が抜けます。先にこの3行を渡し、細かい要件は聞かれたときに開きます。

  1. 払っていない月は、申請したかで別物になる。申請して認められた免除・猶予の月は受給資格期間に数え、全額免除なら老齢基礎年金にも半分が反映されます（期間によって違います）。何もしない未納の月は、どちらにも入りません。
  2. 未納は、障害年金と遺族年金の入口を閉じる。障害基礎年金と遺族基礎年金には納付の要件があります。未納が多いと、状態が重くても支給されないことがあります。働けないときの備えを考える前に、この入口が開いているかを確かめます。
  3. だから最初に見るのは、商品ではなく月別の納付の記録。ねんきん定期便か、ねんきんネットで未納・免除・猶予の月を数えます。さかのぼって申請できるか、追納できるかは年金事務所で確かめ、どうするかはご本人が決めます。

面談の流れ（この順で話すと、押さずに進みます）

  1. 1数えるねんきん定期便の月別の欄で、未納・免除・猶予の月を一緒に数える。
  2. 2期限を見る未納は2年、追納は10年。閉まりかけの月から順に書き出す。
  3. 3窓口へ申請免除・納付猶予・学生納付特例・失業の特例のどれに当たりそうかを、年金事務所か市区町村で相談していただく。
  4. 4持ち帰るその場で決めていただく必要はありません。追納するか、ほかの備えに回すかは、ご家族と話していただく。
1払えない月に引かれた線

「払っていない」には3本の線

国民年金の話が分かりにくいのは、「払っていない月」が全部同じ顔をしているからです。実際には線が3本引かれています。手続きをしたかどうかの線、誰の所得を見るかの線、そしてあとから納められる期限の線。この3本さえ分かれば、窓口で聞くべきことが決まります。

この3つ、答えられますか？

未納と免除同じ「払っていない月」なのに、将来の年金額はどれだけ違う？ 解説へ 免除と猶予審査で見られるのは、本人の所得だけ？　それとも家族も？ 解説へ 追納と時効あとから納められるのは何年前の分まで？　過ぎたらどうなる？ 解説へ

1本目：手続きをしたか、していないか

国民年金の保険料を納めていない月は、大きく2つに分かれます。申請して認められた「免除・猶予」と、何もしていない「未納」です。どちらも通帳からお金は出ていきませんが、記録の上ではまったく別の扱いになります。全額免除の月は、将来の老齢基礎年金に2分の1が反映されます。未納の月は、まるごとゼロです。

全額免除の期間は、老齢基礎年金の額に2分の1が反映されます（平成21年4月以降の期間。それ以前は3分の1）。保険料は1円も納めていないのに、半分は年金になって戻ってくる計算です。根拠：国民年金法第27条、第89条〜第90条の3。額の水準は年度ごとに改定されます

※図は考え方を単純にしたものです。猶予（学生納付特例・納付猶予）は受給資格期間には数えますが、老齢基礎年金の額には反映されません。免除にも全額・4分の3・半額・4分の1の段階があり、反映される割合が変わります。

全額免除が通った

半分は年金になる

保険料はゼロ。それでも老齢基礎年金には2分の1が反映されます。受給資格期間にも数えられ、その期間に初診日のある病気やけがでも、障害基礎年金の納付要件が守られます。

学生納付特例・納付猶予

年金額には反映されない

受給資格期間には数えられ、万一のときの障害・遺族年金の要件も守られます。ただし老齢基礎年金の額には反映されません。追納して初めて、納めた月として計算されます。

何もせず未納のまま

まるごとゼロ

老齢基礎年金の額にも、受給資格期間にも入りません。しかも納付期限から2年で時効になり、あとから納めることもできなくなります。督促や延滞金の対象にもなります。

産前産後期間の免除

納めた月と同じ扱い

出産予定日または出産日が属する月の前月から4か月間（多胎妊娠は6か月間）の保険料が免除され、しかも納付済期間として満額に反映されます。届出をして初めて適用されます。

2本目：誰の所得を見られるか

「収入がないから免除は通るはず」と思って申請し、却下の通知が届いて驚く方がいます。申請免除の審査では、本人だけでなく配偶者と世帯主の所得も見られるからです。実家暮らしなら親の所得が、結婚していれば配偶者の所得が判断材料になります。ここで通らなかった人の受け皿が、納付猶予と学生納付特例です。

納付猶予は50歳未満の方が対象で、審査に世帯主の所得は含まれません（本人と配偶者の所得で判断）。学生納付特例は本人の所得だけで判断されます。根拠：国民年金法第90条の3、平成16年改正法附則。対象年齢や所得基準は改正されることがあります

※所得の基準は式で決まっています。例えば全額免除は「（扶養親族等の数＋1）×35万円＋32万円」が目安です（令和7年度時点）。この式の金額や対象年齢は改正されることがあるため、申請前に日本年金機構または市区町村の国民年金の窓口でご確認ください。

実家暮らしで収入なし

申請免除は通りにくい

本人の所得がゼロでも、世帯主である親の所得が基準を超えていれば申請免除は認められません。ただし50歳未満なら納付猶予、学生なら学生納付特例という別の道があります。

大学生・専門学校生

学生納付特例が使える

本人の所得だけで判断されるため、親の所得がいくらでも関係ありません。在学期間ごとに毎年度申請が必要で、進学・休学・卒業で扱いが変わります。夜間・通信課程も対象です。

退職して国民年金に切替

失業の特例がある

退職した年と翌年度は、本人の所得をゼロとみなして審査する取扱いがあります。離職票や雇用保険受給資格者証の写しを添えて申請します。配偶者・世帯主の所得は通常どおり見られます。

障害基礎年金を受けている

法定免除になる

障害基礎年金の1級・2級を受けている間や生活保護の生活扶助を受けている間は、届出により保険料が免除されます。所得の審査はありません。届出をしないと未納のまま進みます。

3本目：あとから納められる期限

「そのうち余裕ができたら払う」と考えている方に、いちばんお伝えしたいのがこの線です。免除・猶予を受けた期間は10年以内なら追納できます。一方、何もしていない未納の月は納付期限から2年で時効になり、納めたくても納められません。同じ「あとで払う」でも、残された時間が5倍違います。

追納できるのは承認を受けた月の前10年以内の期間です。承認から3年度目以降に追納すると、当時の保険料に加算額が上乗せされます。さかのぼって免除を申請できるのは、原則として過去2年1か月分までです。根拠：国民年金法第94条、第102条。加算額の率は年度により変わります

※図の長さは考え方のイメージです。追納は古い期間から順に納めるのが原則で、承認から3年度目以降は加算額が上乗せされます。免除・猶予の承認を受けていない未納期間は、追納の対象になりません。

就職後に追納した

年金額が満額に近づく

学生時代の学生納付特例を、収入が安定してから追納。追納した月は納付済期間として計算され、老齢基礎年金の額に満額分が反映されます。納めた保険料は社会保険料控除の対象です。

10年たってから気づいた

もう追納できない

免除・猶予を受けていても、10年を過ぎた期間は追納できません。学生時代の2年分を放置すると、20代のうちに窓が閉まる計算になります。まずは残り期間の確認からです。

督促状を放置した

延滞金・差押えも

未納が続くと催告状・督促状が届き、それでも納付や相談がないと延滞金や財産の差押えに進むことがあります。世帯主や配偶者に納付義務が及ぶ場合もあります。放置がいちばん高くつきます。

さかのぼって申請した

過去2年1か月まで

免除・猶予は、申請時点からさかのぼって2年1か月分まで申請できます。「未納だと思っていた月」が免除に切り替われば、年金額も、万一のときの要件も救われます。まず窓口へ。

3本の線に共通するのは、どれも「自分から動いた人だけ」が使える仕組みだということです。免除も猶予も追納も、役所から案内が来て自動的に始まることはありません。なお、追納した保険料は全額が社会保険料控除の対象になりますが、個別の税額計算・申告については税理士にご確認ください。
2いちばん多い誤解

「未納でも同じ」を解剖する

「どうせ払っていないんだから、未納も免除も同じでしょう」。これがいちばん多い誤解です。ここでは、その言葉に数字で答えます。まず表で違いを並べます。ご自身の月数は、ねんきん定期便かねんきんネットで数えてみてください。

まず、同じ「納めていない月」を2つ並べてみます。通帳から出ていく金額はどちらもゼロですが、記録の上ではこれだけ違います。

くらべる点未納のまま何もしない全額免除申請して承認
老齢基礎年金の額への反映ゼロ2分の1
受給資格期間（10年）数えない数える
障害・遺族年金の納付要件数えない数える
あとから納められる期間2年で時効10年間 追納できる
督促・延滞金・差押え対象になりうるありません

※全額免除の反映割合は平成21年4月以降の期間についてのものです（それ以前は3分の1）。4分の3免除・半額免除・4分の1免除では反映割合が変わります。学生納付特例と納付猶予は、受給資格期間と納付要件では免除と同じ扱いですが、年金額には反映されません。

本当に怖いのは、年金額よりも先にある3つ

  1. 受給資格の10年に届かない老齢基礎年金は、保険料納付済期間と免除・猶予期間などを合わせて10年以上ないと、1円も受け取れません。未納の月はこの10年に数えられないため、記録が薄い方ほど先に確認が必要です。
  2. 障害年金の入口で止まる病気やけがで働けなくなったときの障害基礎年金には、保険料の納付要件があります。未納が多いと、障害の状態がどれだけ重くても支給されないことがあります。ここが取り返しのつかない場面です。
  3. 残された家族の遺族基礎年金も同じ18歳到達年度末までのお子さんがいるご家庭に支給される遺族基礎年金にも、同じ納付要件があります。ご本人が亡くなったあと、ご家族が窓口で初めて知る、という形になりがちです。

いちばん多い失敗は「そのうち払うつもりだった」未納の月は納付期限から2年で時効になり、納めたくても納められなくなります。一方、免除や猶予の承認を受けていれば10年追納できます。同じ「あとで払う」でも残り時間が5倍違うのに、その差を生むのは申請書1枚です。払えるようになってから考えるのではなく、払えない月が来た時点で申請しておくのが順番です。

数字を見ると「思ったより減らない」と感じる方も、「思ったより減る」と感じる方もいます。どちらの感想も正解です。大事なのは、その減り方をご自身で選んだのか、知らないうちにそうなっていたのか、という点です。

「じゃあ全部免除にすればいい？」——対策のワナ
  • 免除は所得の審査があります。希望すれば通るものではなく、本人・配偶者・世帯主の所得が基準以下であることが前提です。
  • 猶予は年金額に反映されません。納付猶予・学生納付特例は、追納しない限り老齢基礎年金の計算から抜けたままです。
  • 一部免除は納めないと未納になります。4分の3免除などで承認されても、減額後の保険料を納めなければ、その月は未納として扱われます。
  • 免除中は付加保険料を納められません。上乗せを増やしたい方は、免除・猶予との組み合わせに注意が必要です（産前産後期間の免除中は納付できます）。

順番があります。払えない時期は免除・猶予で守り、払えるようになったら追納で埋め、余裕が出たら付加保険料や他の備えを考える。この順番さえ守れば、大きく外すことはありません。
